# 桌面 AI 精灵

桌面 AI 精灵是一款 AI 卡通形象创作工具。上传人物、宠物或其他图片后，视觉模型会分析画面中的外观特点，再生成一个全新设计的大头小身子卡通精灵。它以图中人物的发型、配饰、颜色与神态作为创作线索，不是把照片抠出来，也不是直接给照片套滤镜。

## 创作风格

- **夸张大头萌系**：放大头部比例，突出眼睛和表情。
- **怪诞超现实**：采用不对称比例、奇特配色和戏剧化神态。
- **几何立体抽象**：用立体切面和撞色几何形状重塑角色。
- **俏皮讽刺漫画**：强化眉眼、嘴角和漫画线条，呈现调皮的角色气质。
- **潮流波普贴纸**：采用高对比色彩、漫画网点和贴纸视觉元素。
- **复古像素桌宠**：以复古游戏像素风格重新设计角色。

## 3D 材质

可选择盲盒树脂、电影 CGI、手捏黏土或毛绒布偶质感。材质选择会影响角色整体的表面表现。

## 主要功能

- 上传图片并提取可辨认的视觉特点。
- 选择主体类型、创作风格和 3D 材质。
- 调整角色与参考图片的相似程度。
- 生成全新的卡通精灵图像。
- 提供 30 种界面语言选项；部分语言文案与自动翻译仍在完善中。
- 支持 Windows 本地运行，并提供 Docker 与 Render 部署配置。

## 本地运行

1. 在 Windows 上双击 `start-windows.bat`。
2. 打开 `http://127.0.0.1:8765`。
3. 在 AI 接口设置中填写 Cloudflare Account ID 和 API Token，或在项目目录的 `.env` 文件中配置。
4. 上传图片，选择风格和材质后生成精灵。

`.env` 不会被 Git 跟踪。请勿将 API Token 提交到公开仓库。

## AI 与隐私

图像特征分析与角色生成通过配置的 Cloudflare Workers AI 完成。使用时，上传的图片会发送到所配置的 Cloudflare AI 服务处理。

公网测试版通过访问口令保护 API，访客不能修改服务器共享的 AI 密钥；生成图不会持久保存到托管项目目录。生成请求会使用配置的 Cloudflare 账号额度。

## 公网测试部署

项目包含 `Dockerfile` 和 Render Blueprint（`render.yaml`）。部署时需要在 Render 环境变量中设置：

- `APP_ACCESS_CODE`：私有测试访问口令。
- `CLOUDFLARE_ACCOUNT_ID`：Cloudflare 账号 ID。
- `CLOUDFLARE_API_TOKEN`：具有 Workers AI 权限的 API Token。

公网版会隐藏并禁用 AI 动作生成功能，也不支持从网页启动 Windows 桌面宠物。测试版暂未实现个人账户、每用户生成额度、付费或邀请奖励系统，不适合无访问控制地向公众开放。
