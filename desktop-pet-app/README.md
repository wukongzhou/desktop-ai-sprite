# 桌面精灵

会在电脑桌面上随机走动的精灵，有自己的性格，会学习，听得懂中英文指令，会"吃掉"被删除的文件。

## 运行和打包

需要先安装 Node.js，然后在本文件夹里：

```
npm install
npm start        # 直接运行
npm run dist     # 打包成安装包，生成在 dist/ 里
```

安装包要在对应系统上打：Windows 的 .exe 在 Windows 上打，Mac 的 .dmg 在 Mac 上打。

## 怎么玩

- 单击：戳它一下（它可能开心，也可能发火）
- 双击：打开输入框，用中文或英文对它说话，回车发送
- 右键：退出

## 两个本地小模型（都不联网、不花钱）

**小模型 1：随机动作 + 性格 + 学习（`brain.js`）**
每个动作想做的程度 = 性格决定的倾向 × 学到的偏好。夸它或戳它开心时，它当时在做的动作会变得更常出现；骂它则相反。偏好按时段（凌晨/上午/下午/晚上）分开学，会慢慢养成习惯。还有心情：被夸变好、被骂变差，心情差又脾气大的时候会不听话。记忆保存在用户数据目录的 `brain.json`，删掉它就是让精灵重新开始。

**小模型 2：听懂指令（`understand.js`）**
把语言包里的例句拆成特征，用朴素贝叶斯分类出意图，中英文通用。能听懂：过来、别动、自己去玩、睡觉、起床、跳舞、夸奖、责骂、查邮件（还没真的实现，会装委屈）。句子里认识的部分太少就判定为没听懂，精灵会冒个问号。

### 增加新语言

不用改代码。照着 `lang/zh.json` 的格式写一个语言包（例如 `es.json`），放进 `lang/` 文件夹，或放进用户数据目录下的 `lang/` 文件夹（这样不用重新打包），重启精灵就生效。中日韩文字按字切分，其他文字按单词切分。

### 增加新本领

在 `main.js` 的 `skills` 里加一项（比如 `mail` 真的去读邮件），再在各个语言包里加上对应说法。

## 接 AI（可选）

`config.json` 里的 `apiUrl` 填上服务器地址后，精灵遇到事件时会 POST `{ personality, event }`。目前有两种事件：

- `file_deleted`：返回 `{ "emoji": "😋" }`，精灵用这个表情
- `command`：本地模型没听懂时，返回 `{ "intent": "come" }`，让 AI 帮忙判断

不填则完全本地运行。

## 已知限制

- 窗口是 150x150 的透明方块，方块范围内的点击会被精灵窗口接住
- 文件被移到别的文件夹也会被当成"删除"
- 只监控 `watchDirs` 里的文件夹（不含子文件夹），只在主屏幕活动
- 指令理解靠例句，说法差得太远会听不懂，可以往语言包里补例句
