# 桌面精灵

会在电脑桌面上随机走动的精灵，有自己的性格，会学习，听得懂中英文指令，会"吃掉"被删除的文件。

## 运行和打包

需要先安装 Node.js，然后在本文件夹里：

```
npm install
npm start        # 直接运行
npm run dist     # 打包成安装包，生成在 dist/ 里
```

安装包要在对应系统上打：Windows 的 .exe 在 Windows 上打，Mac 的 .dmg 在 Mac 上打。

## 怎么玩

- 单击：戳它一下（它可能开心，也可能发火）
- 双击：打开输入框，用中文或英文对它说话，回车发送
- 右键：退出

## 安全限制（仅限本机，只听主人的）

规则写在 `guard.js` 开头，`main.js` 里强制执行：

1. **不联网**：默认不发任何网络请求，窗口本身也被禁止访问网络。只有在 `config.json` 里把 `allowNetwork` 设为 `true` 并填了 `apiUrl` 才会连，远程地址必须是 https。
2. **只听主人**：指令只接受精灵自己窗口的输入框，限制长度（60 字）和频率（5 秒内最多 5 条）。没有任何远程控制入口。
3. **只做白名单里的事**：精灵能做的事只有 `main.js` 里 `skills` 列出的那些，而且都只是动作和表情。语言包只能加新说法，不能创造新本领；AI 返回的内容也要过白名单检查。
4. **不动你的文件**：监控文件夹是只读的，只"看"文件是否消失，从不删除、修改、移动、上传任何文件；只写自己的数据目录（性格和学习记忆）。只允许监控个人文件夹里的目录。
5. **不碰别的**：不读屏幕、键盘、麦克风、摄像头，不执行命令，不下载代码，不打开网页，不给任何设备权限。
6. **学习有边界**：只调整动作偏好和心情，数值有上下限，不会修改自己的代码。
7. 同一台电脑上只允许运行一只。

## 两个本地小模型（都不联网、不花钱）

**小模型 1：随机动作 + 性格 + 学习（`brain.js`）**
每个动作想做的程度 = 性格决定的倾向 × 学到的偏好。夸它或戳它开心时，它当时在做的动作会变得更常出现；骂它则相反。偏好按时段（凌晨/上午/下午/晚上）分开学，会慢慢养成习惯。还有心情：被夸变好、被骂变差，心情差又脾气大的时候会不听话。记忆保存在用户数据目录的 `brain.json`，删掉它就是让精灵重新开始。

**小模型 2：听懂指令（`understand.js`）**
把语言包里的例句拆成特征，用朴素贝叶斯分类出意图，中英文通用。能听懂：过来、别动、自己去玩、睡觉、起床、跳舞、夸奖、责骂、查邮件（还没真的实现，会装委屈）。句子里认识的部分太少就判定为没听懂，精灵会冒个问号。

### 增加新语言

不用改代码。照着 `lang/zh.json` 的格式写一个语言包（例如 `es.json`），放进 `lang/` 文件夹，或放进用户数据目录下的 `lang/` 文件夹（这样不用重新打包），重启精灵就生效。中日韩文字按字切分，其他文字按单词切分。

### 增加新本领

在 `main.js` 的 `skills` 里加一项，再在各个语言包里加上对应说法。

## 接 AI（可选，默认关闭）

`config.json` 里把 `allowNetwork` 设为 `true`，并填上 `apiUrl`，精灵遇到事件时会 POST `{ personality, event }`。目前有两种事件：

- `file_deleted`：返回 `{ "emoji": "😋" }`，精灵用这个表情（只收 emoji）
- `command`：本地模型没听懂时，返回 `{ "intent": "come" }`，让 AI 帮忙判断（只收白名单内的意图）

注意：开启后，文件名和你输入的指令会发给这个服务器。不开启则完全本地运行。

## 已知限制

- 窗口是 150x150 的透明方块，方块范围内的点击会被精灵窗口接住
- 文件被移到别的文件夹也会被当成"删除"
- 只监控 `watchDirs` 里的文件夹（不含子文件夹），只在主屏幕活动
- 指令理解靠例句，说法差得太远会听不懂，可以往语言包里补例句
