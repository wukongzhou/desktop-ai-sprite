# 桌面精灵（最小版本）

会在电脑桌面上随机走动的精灵，有自己的性格，会"吃掉"被删除的文件。

## 运行

需要先安装 Node.js，然后在本文件夹里：

```
npm install
npm start
```

右键精灵可以退出，点一下精灵可以和它互动。

## 已经有的

- 随机行为：走、跑、坐、睡觉、发呆、发脾气
- 性格：第一次启动随机生成（脾气、食欲、精力），之后保持不变，影响它的行为
- 吃文件：监控 `config.json` 里的文件夹，文件消失就吃掉；文件越大吃得越久，太大会吃撑躺平
- 不会说话，只用动作和表情气泡

## 接 AI（可选）

把 `config.json` 里的 `apiUrl` 填成你服务器的地址，精灵遇到事件时会 POST：

```
{ "personality": {...}, "event": { "type": "file_deleted", "name": "...", "sizeMB": 12.3, "fullness": 40 } }
```

服务器返回 `{ "emoji": "😋" }`，精灵就用这个表情。不填的话完全本地运行，不花钱。

## 已知限制

- 窗口是 150x150 的透明方块，方块范围内的点击会被精灵窗口接住
- 文件被移到别的文件夹也会被当成"删除"
- 只监控 `watchDirs` 里的文件夹（不含子文件夹）
- 只在主屏幕上活动
