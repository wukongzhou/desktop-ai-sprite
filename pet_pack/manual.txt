桌面 AI 精灵 · 安装与使用手册
Desktop AI Sprite · Installation and User Guide
================================================

一、启动 | Start
1. 把本 ZIP 解压到一个单独文件夹。
2. Windows 10/11 安装 Python 3.9 或更新版本，并确保 tkinter 可用。
3. 双击「启动精灵.bat」。首次启动会安装 Pillow；桌面精灵不要求本机 GPU。
4. 精灵默认不会加入开机启动。右键菜单中可以由你主动开启或关闭。

二、AI 对话 | AI chat
1. 右键精灵，选择「设置 AI 接口」。
2. 粘贴你自己的 NVIDIA API Key，保留默认模型 z-ai/glm-5.3-flash，点击「测试连接」，通过后保存。
3. 右键选择「跟它聊聊」，输入消息。没有 Key 或服务暂不可用时，精灵仍可使用本地规则和性格回应。
4. NVIDIA 的免费试用端点、额度、限速和模型可用性由 NVIDIA 管理，可能随时变化。

隐私提示 | Privacy notice
- API Key 只写入当前 Windows 用户的 AppData\Roaming\DesktopAISprite\pet_ai_config.json，不进入安装包或 Git 仓库。该本机配置文件为明文，请勿分享。
- 使用云端对话时，你输入的聊天文字、精灵性格和最多五条已记忆事实会发送给 NVIDIA NIM 生成回复。避免发送密码、支付信息或其他敏感资料。NVIDIA 试用服务的数据处理以其当时的条款和隐私政策为准。
- 桌面精灵的 AI 对话只生成文字，不会自行操作或删除文件。文件修复、移入回收站需要你从菜单主动选择。
- 图片生成器的 Cloudflare 图像服务与桌宠的 NVIDIA 对话接口是两项独立配置。

三、操作 | Interaction
- 左键拖动：移动精灵。
- 双击：听它说一句心里话。
- 右键：聊天、设置接口、摸摸头、陪它玩、睡觉/叫醒、查看性格与记忆。
- 拖入文件后，可从菜单选择修复或移进回收站；操作由主人发起。
- 右键菜单可以主动开启/关闭开机启动；初次启动不会自动添加启动项。

四、技术说明 | Technical notes
- NVIDIA API 使用 OpenAI 兼容的 HTTPS chat-completions 接口；`pet_ai.py` 仅使用 Python 标准库。
- 默认模型为 NVIDIA API Catalog 当前列出的 `z-ai/glm-5.3-flash`，可在接口设置中更改。
- 若连接失败，请检查 API Key、当前模型是否仍开放试用、NVIDIA 账户的可用额度及网络连接。
